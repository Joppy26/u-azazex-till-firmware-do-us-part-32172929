## The vow

> "I promise to love you through every firmware update, every low-battery warning, and every surprise reboot, until our uptime finally runs out."

## How it runs

`main.ts` writes the vow, exactly as written, to `/output/entry.txt`. No network, no randomness, no external tools: the output is the same on every run.
